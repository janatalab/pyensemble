PyEnsemble Examples

Explore example definitions, participant flows, and experiment-specific Python callbacks. Start with the importable examples below; the advanced integrations are optional.

Start here: import an example definition

  1. Open Import JSON.
  2. Select an Experiment export from pyensemble/experiments/debug/assets/definition-exports/.
  3. Choose Validate only first. If validation succeeds, import it as a new draft. The JSON title/name is used automatically unless it conflicts with an existing definition.
  4. Review the imported Experiment, Forms, and Questions in the editors before creating a ticket or running a participant session.

Experiment exports include their nested Forms and Questions. You usually do not need to import the corresponding Form or Question exports separately. Imports create unlocked drafts, not releases.

More examples

  • Further Participation and Email Login demonstrate participant registration/login and Python callbacks. Email uses the local console backend; messages appear in the server output.
  • Prolific Redirect Test demonstrates completion redirection. Replace its placeholder completion code with a valid code before use.
  • Form and Question exports show how smaller definition objects can be imported independently.
  • Python setup examples demonstrate programmatic creation of PyEnsemble objects. They are administrative examples and may create or replace database relationships; use only in a disposable local database.

See pyensemble/experiments/debug/README.md in the repository for import details, audio setup, asset notes, and the complete catalog.
